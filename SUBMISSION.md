# Builder contribution: Intelligent Contracts

## Title

ChangeGate — Evidence-backed IT Change Compliance

## Description (under 1000 characters)

ChangeGate audits production software change governance through a standalone GenLayer Intelligent Contract. It locks owner-bound policies and commit-pinned, SHA-256/byte-bound evidence. Deterministic checks enforce approval identities and order, separation of duties, artifact matching, deployment windows, tests and rollback readiness. Leaders and validators independently retrieve evidence and assess authorization scope, test coverage and rollback adequacy using native GenLayer consensus. Exact quotations ground findings; validators compare substantive control decisions. Outcomes: COMPLIANT, CONDITIONAL, VIOLATION and INCONCLUSIVE. Includes bounded evaluations, append-only hash-linked receipts, adversarial fixtures, 41 passing local tests, GenVM validation and documentation. Live Studionet audits finalized successfully with COMPLIANT and VIOLATION receipts. Evidence truth remains an organizational trust assumption; this is an audit primitive, not a compliance guarantee.
